# long.play — первый экран

Учебная вёрстка (домашнее задание): копия первого экрана сайта **long.play** по видео-референсу, ПК-версия.
Сервис по оцифровке видеокассет: сумерки, холм с золотой травой, на вершине светится ретро-телевизор.

Сайт открывается двойным кликом по `index.html` — без сервера, сборщиков и интернета.

## Технологии

- **HTML + CSS + JavaScript** без фреймворков и библиотек.
- **CSS 3D** — телевизор нарисован кодом: корпус собран из 44 скруглённых слоёв, у каждого свой `translateZ`.
  Получается объёмная коробка со скруглёнными рёбрами, которую можно поворачивать.
- **WebGL 2** (без библиотек) — ~55 000 травинок рисует видеокарта: ветер, свет от телевизора, размытие ближней травы и реакция на курсор.
- **Canvas 2D** — частицы-«боке» (210 шт.).
- **Web Animations API** — интро: текст и кнопка проявляются из размытия.
- **`requestAnimationFrame` + плавная пружина (SmoothDamp)** — параллакс от мыши и поворот телевизора с инерцией, как в оригинале.
- **backdrop-filter** — матовая нижняя полоса.
- **ffmpeg** — сжатие и цветокоррекция видео травы, бесшовный луп.
- Node.js + Playwright использовались **только для проверки** (скриншоты и сравнение с референсом), в сайт не входят.

## Структура

```
index.html            разметка
style.css             стили (все размеры в --u = 1/1920 ширины окна)
script.js             анимации
assets/fonts/         шрифты (.woff2) и fonts.css со шрифтами в base64
assets/video/         grass-near.mp4/webm — размытая трава переднего плана (используется);
                      grass.mp4/webm — прежняя подложка холма (сейчас не используется)
assets/img/           постеры видео (показываются, пока видео грузится)
```

Шрифты встроены в `assets/fonts/fonts.css` в формате base64: Chrome не загружает
обычные файлы шрифтов, если страница открыта двойным кликом (`file://`).

## Анимации

| Что | Как сделано |
| --- | --- |
| Интро | Кнопка появляется из размытия (0–1.1 с), текст — волной по словам слева направо (вторая строка чуть позже), полоса PRIVACY-FIRST — с 0.7 до 1.4 с. Тайминги сняты по кадрам референса. |
| «Дыхание» камеры | Медленный зум 1 → 1.05 и сдвиг, цикл 18 с (считается в JS). |
| Параллакс | Слои (небо, облака, горы, холм, телевизор, частицы, ближняя трава) сдвигаются от мыши с разной «глубиной». Движение сглажено пружиной с инерцией ~0.5 с. |
| Телевизор | Поворачивается вслед за курсором и слегка покачивается. Экран мерцает, свечение двигается вместе с экраном. |
| Трава | WebGL: каждая травинка — изогнутая кривая, качается на ветру. Под травой сетка «пружинок»: курсор расталкивает травинки, они пружинисто возвращаются. Ближняя трава (размытое стоковое видео + крупные размытые травинки) даёт эффект малой глубины резкости. |
| Частицы | Canvas: «снежинки»-боке разного размера и прозрачности медленно падают и покачиваются, у травы мерцают «светлячки». |
| Ховеры | Плашки меню светлеют. Главная кнопка немного увеличивается, а волны «≈» на иконке начинают двигаться. |
| Доступность | При `prefers-reduced-motion` анимации отключаются, сцена остаётся статичной. |

Для проверки можно остановить интро на нужной секунде: `index.html?t=0.8`.
